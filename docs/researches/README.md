# RESEARCHES — 机制原理研究索引

沉淀「为什么这样设计」的过程证据：问题、假设、验证手段、结论。结论生效后，正式文档只引用结论，过程留在这里。

## 登记规则

- 一篇调研一个文件，命名 `NNNN-<kebab-topic>.md`（如 `0001-sqlite-wal-latency.md`）。
- 每篇必须有结论段；无结论的调研标记为「未收敛」，不得据此做决策。
- 结论若改变了系统结构或流程，必须同时新增/更新 `docs/DECISIONS.md` 中的 ADR，并在此处互相引用。
